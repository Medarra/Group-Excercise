WEEK 12 — STUDENT STARTER
Extract the ZIP. In editor.p5js.org create a sketch, replace sketch.js and upload photo.png and overlay.png to the root. Run. Alternatively serve this folder using python -m http.server 8000 and visit http://localhost:8000 (internet required for p5.js CDN).
The initial display, reset and save are scaffolded. Complete the TODOs for filters, inversion and blending. Sample images are original synthetic graphics, supplied for practice.
